# High Performance C++ - Mastery Checklist

## Core Concepts

Track your understanding of key concepts:

### Phase 1: Foundations
- [ ] Compilation model (preprocessor, compiler, linker)
- [ ] Stack vs. heap memory layout
- [ ] CPU cache hierarchy and data locality
- [ ] Value semantics vs. reference semantics
- [ ] Struct alignment and padding

### Phase 2: Ownership & Abstraction
- [ ] RAII pattern
- [ ] Copy vs. move semantics
- [ ] Smart pointers (unique_ptr, shared_ptr)
- [ ] Templates and monomorphization
- [ ] Inline functions and compiler optimizations

### Phase 3: Containers & Data Design
- [ ] STL container performance tradeoffs
- [ ] std::vector internals
- [ ] Hash map internals
- [ ] STL algorithms and iterators
- [ ] Data-Oriented Design (SoA vs AoS)

### Phase 4: Profiling & Optimization
- [ ] Benchmarking fundamentals
- [ ] Profiling tools (perf, Instruments)
- [ ] Reading compiler output (Godbolt)
- [ ] Common optimization patterns (SSO, reserve, string_view)
- [ ] Real-world case studies
