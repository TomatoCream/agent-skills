* Overview & Core Mechanisms
The =org-anki= package synchronizes Org-mode entries to Anki via the AnkiConnect HTTP API (version 6).
It parses headings, entry bodies, properties, and tags, converting Org syntax and MathJax environments to HTML before pushing to Anki.

** Essential Interactive Commands
- =M-x org-anki-sync-entry= :: Syncs or updates the single card under point. Writes back =:ANKI_NOTE_ID:= upon creation.
- =M-x org-anki-sync-all= :: Iterates through entries in the buffer (matching =ANKI_MATCH= / =org-anki-default-match=, skipping via =org-anki-skip-function=), filtering out incomplete notes (all fields must have values), and syncs them in a single batch (=multi= API call).
- =M-x org-anki-update-all= :: Fast sync for existing notes only (matches entries where =ANKI_NOTE_ID<>""=).
- =M-x org-anki-update-dir= :: Runs =org-anki-update-all= across every =.org= file in a directory. Use =C-u= prefix to recurse subdirectories.
- =M-x org-anki-delete-entry= :: Deletes the card under point from Anki (prompts for confirmation) and removes the local =:ANKI_NOTE_ID:= property.
- =M-x org-anki-delete-all= :: Deletes all notes in the buffer that possess an =ANKI_NOTE_ID= from Anki, stripping the properties.
- =M-x org-anki-cloze-dwim= :: Wraps the active region or the word under point in Anki cloze syntax: ={{c<ARG>::<text>::<hint>}}=. Defaults to argument 1 if no prefix argument is given.
- =M-x org-anki-browse-entry= :: Opens Anki's GUI card browser filtered to =nid:<ANKI_NOTE_ID>= using AnkiConnect's =guiBrowse=.
- =M-x org-anki-import-deck= :: Imports an existing deck from Anki via =findNotes= + =notesInfo= and converts HTML back to Org headings/bodies using Pandoc.
- =M-x org-anki-add-model= :: Registers a new note type and its ordered field names into =org-anki-model-fields= at runtime.

** Property & Value Resolution Hierarchy
For properties like =ANKI_DECK= and =ANKI_NOTE_TYPE=, resolution proceeds in order:
1. Item's local property drawer (=:ANKI_DECK:=).
2. Inherited property from parent headings.
3. In-buffer global keyword (e.g., =#+ANKI_DECK: ...= or =#+PROPERTY: ANKI_DECK ...=).
4. Elisp variable default (=org-anki-default-deck= / =org-anki-default-note-type=).

* Card Type 6: Rich Media & Assets :anki:media:

** Media Strategies & Asset Rules :noexport:
=org-anki= inspects HTML =src= and =href= attributes for local file links, transforms the filename to =<inode>_<basename>= (stripping =#= signs to maintain Anki compatibility), and synchronizes the asset via one of two media strategies:
1. ='filesystem= (default): Direct local filesystem copy to Anki's media directory (fast).
2. ='http=: Reads binary contents into temporary buffers, base64-encodes them, and pushes them via =storeMediaFile= AnkiConnect API calls.

* Card Type 7: Tagging Mechanics & Hierarchical Tags :anki:languages__cpp:memory__alignment:

** Inheritance, Hierarchy, and Filtering
:PROPERTIES:
:ANKI_NOTE_ID: 1790616124069
:END:
How does structure packing affect cache performance?
Padding bytes prevent unaligned memory access penalties at the cost of footprint. Misaligned loads spanning two cache lines trigger double bus cycles.

*** Tagging Features Illustrated :noexport:
- Tag Inheritance :: Inherits =languages__cpp= and =memory__alignment= from parent headings if =org-anki-inherit-tags= is non-nil.
- Global Buffer Tags :: Appends any tags defined in =#+ANKI_TAGS:=.
- Hierarchical Tags :: When =org-anki-hierarchical-tags-separator= is set to ="__"=, =languages__cpp= synchronizes to Anki as the nested tag =languages::cpp=.
- Ignored Tags :: Tags present in =org-anki-ignored-tags= (e.g., =noexport=, =anki=) are filtered out prior to API payload construction.
- Tag Differential Syncing :: =org-anki--tag-diff= computes additions and deletions relative to existing tags on Anki notes and executes =addTags= / =removeTags= API calls.

* Companion Emacs Configuration (Elisp Setup)
Below is the idiomatic configuration enabling the full suite of features exercised above:

#+BEGIN_SRC emacs-lisp
;; Connection & API Security
(setq org-anki-ankiconnnect-listen-address "http://127.0.0.1:8765"
      org-anki-api-key nil) ; Set string if AnkiConnect uses authentication

;; Default Fallbacks
(setq org-anki-default-deck "Default"
      org-anki-default-note-type "Basic"
      org-anki-allow-duplicates nil)

;; Media Transfer Engine: 'filesystem (local, fast) or 'http (remote/containerized)
(setq org-anki-media-method 'filesystem)

;; Tag Management
(setq org-anki-inherit-tags t
      org-anki-ignored-tags '("anki" "noexport" "todo")
      org-anki-hierarchical-tags-separator "__") ; Maps "tag__subtag" -> "tag::subtag"

;; Register Custom Models & Field Layouts
(setq org-anki-model-fields
      '(("Basic" "Front" "Back")
        ("Basic (and reversed card)" "Front" "Back")
        ("Basic (optional reversed card)" "Front" "Back")
        ("NameDescr" "Name" "Descr")
        ("Cloze" "Text" "Extra")
        ("ArchitectureDecision" "Context" "Decision" "Tradeoffs")))

;; Or register models dynamically via public API:
;; (org-anki-add-model "ArchitectureDecision" "Context" "Decision" "Tradeoffs")

;; HTML to Org Converter for import (defaults to Pandoc shell pipe)
(setq org-anki-html-to-org 'org-anki--html-to-org)
;; Field Pre-processing / Templates (String -> String transformers per field)
(setq org-anki-field-templates
      '(("ArchitectureDecision"
         ("Context" . (lambda (val) (concat "<div class=\"context\">" val "</div>")))
         ("Decision" . (lambda (val) (concat "<b>Decision:</b> " val))))))

;; Selective Sync Filters
(setq org-anki-default-match "anki-noexport"
      org-anki-skip-function nil)

;; Keybindings
(define-key org-mode-map (kbd "C-c a s") #'org-anki-sync-entry)
(define-key org-mode-map (kbd "C-c a a") #'org-anki-sync-all)
(define-key org-mode-map (kbd "C-c a u") #'org-anki-update-all)
(define-key org-mode-map (kbd "C-c a d") #'org-anki-delete-entry)
(define-key org-mode-map (kbd "C-c a c") #'org-anki-cloze-dwim)
(define-key org-mode-map (kbd "C-c a b") #'org-anki-browse-entry)
#+END_SRC
