*** Front :noexport:
What are the semantics of an atomic *Compare-And-Swap (CAS)* operation?
What condition determines whether the memory update succeeds?

#+BEGIN_SRC c
bool atomic_compare_and_swap(uint64_t *ptr, uint64_t expected, uint64_t desired);
#+END_SRC

*** Back :noexport:
*Atomic Semantics:*
1. Reads the current value at ~*ptr~.
2. If ~*ptr == expected~:
   - Writes ~desired~ into ~*ptr~.
   - Returns ~true~ (operation succeeded).
3. If ~*ptr != expected~:
   - Leaves ~*ptr~ unchanged.
   - Returns ~false~ (operation failed).

The entire read-compare-write sequence executes as an *indivisible hardware transaction*.

** Virtual Memory Translation Complexity :mmu:
:PROPERTIES:
:ANKI_NOTE_TYPE: Basic
:END:

*** Front :noexport:
In a 4-level page table architecture on x86-64:
What is the worst-case number of memory accesses required to translate a virtual address to a physical address upon a *TLB miss*?

*** Back :noexport:
*4 memory accesses* (one read for each table hierarchy level):
1. Page Map Level 4 (PML4)
2. Page Directory Pointer Table (PDPT)
3. Page Directory (PD)
4. Page Table (PT)

Each level reads an 8-byte entry to determine the base address of the next level.
(A 5th memory access then fetches the actual target data).

** Balanced Red-Black Tree Lookup Bound :complexity:
:PROPERTIES:
:ANKI_NOTE_TYPE: Basic
:END:

*** Front :noexport:
What is the maximum height and worst-case search complexity of a Red-Black Tree with $n$ internal nodes?

*** Back :noexport:
*Height Bound:*
$$h \le 2 \log_2(n + 1)$$

*Worst-case Search Complexity:*
$$O(\log n)$$

Proof: Every root-to-leaf path contains the same number of black nodes ($bh$), and no path has two consecutive red nodes. The shortest possible path has length $bh$, and the longest has length $\le 2bh$.
