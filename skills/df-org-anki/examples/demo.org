* Images and local media                                                :anki:
Local file links are copied into Anki's media folder (or uploaded over HTTP
when =org-anki-media-method= is ='http=), with an inode-prefixed filename:

[[file:~/pics/diagram.png]]

#+BEGIN_EXPORT html
<img src="file:///home/df/pics/cycle.png" alt="cycle">
<a href="notes.pdf">attached pdf</a>
#+END_EXPORT

# org-anki--collect-file-links scans src=/href= in the exported HTML;
# file:// and bare relative paths are localized, http(s):// are left alone.

#   org-anki-sync-entry     sync note at point (add or update + tag diff)

#   org-anki-cloze-dwim     wrap region/word as {{cN::...::hint}}
