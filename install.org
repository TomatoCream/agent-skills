# Skill Installation Guide

This repository contains skills for coding agents (opencode, claude-code, etc.)

* Installing Skills

Use =npx skills install= with the repository and skill path:

#+BEGIN_SRC bash
npx skills install tavily-ai/skills skills/tavily-search
npx skills install tavily-ai/skills skills/tavily-extract
npx skills install tavily-ai/skills skills/tavily-map
npx skills install tavily-ai/skills skills/tavily-crawl
npx skills install tavily-ai/skills skills/tavily-best-practices
npx skills install obra/superpowers skills/brainstorming
npx skills install obra/superpowers skills/writing-plans
npx skills install obra/superpowers skills/executing-plans
npx skills install obra/superpowers skills/subagent-driven-development
npx skills install obra/superpowers skills/dispatching-parallel-agents
npx skills install obra/superpowers skills/systematic-debugging
npx skills install obra/superpowers skills/test-driven-development
npx skills install obra/superpowers skills/verification-before-completion
npx skills install obra/superpowers skills/using-git-worktrees
npx skills install obra/superpowers skills/finishing-a-development-branch
npx skills install obra/superpowers skills/receiving-code-review
npx skills install obra/superpowers skills/requesting-code-review
npx skills install obra/superpowers skills/writing-skills
npx skills install obra/superpowers skills/using-superpowers
npx skills install 199-biotechnologies/claude-deep-research-skill
#+END_SRC

* opencode

Install opencode skills:
- Skills are installed via =npx skills install=
- See [[https://opencode.ai][opencode.ai]] for documentation
- Agent reads skills from =skills/= directory
- Use =skill= tool to load a skill

* claude (Code)

Install claude skills:
- Skills are installed via =npx skills install=
- See [[https://docs.anthropic.com/en/docs/claude-code][claude-code docs]] for documentation
- Skills installed to =~/.claude/skills/=
