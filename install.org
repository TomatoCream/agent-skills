* Skill Installation Guide

This repository contains skills for coding agents (opencode, claude-code, etc.).

*NOTE: This file is idempotent. Running installation commands multiple times is safe.*

* Finding Install Instructions

For any skill, check its SKILL.md for:
- Required external CLI tools (e.g., tavily CLI)
- Installation commands specific to that skill
- Any authentication/setup steps required

If a skill requires additional CLI tools not listed here:
1. Web search for the tool's official documentation
2. Look for install instructions in the tool's GitHub repo
3. Add the tool and install command to the Additional Tools table below

* Installing Skills

Use =npx skills install= with the repository and skill path:

#+BEGIN_SRC bash
# Tavily skills (web search, extraction, crawling)
npx skills install tavily-ai/skills skills/tavily-search
npx skills install tavily-ai/skills skills/tavily-extract
npx skills install tavily-ai/skills skills/tavily-map
npx skills install tavily-ai/skills skills/tavily-crawl
npx skills install tavily-ai/skills skills/tavily-best-practices
npx skills install tavily-ai/skills skills/tavily-cli
npx skills install tavily-ai/skills skills/tavily-research

# Superpowers skills (development workflows)

* opencode

Install opencode skills:
- Skills are installed via =npx skills install=
- See [[https://opencode.ai][opencode.ai]] for documentation
- Agent reads skills from =skills/= directory
- Use =skill= tool to load a skill

* claude (Code)

Install claude skills:
- Skills are installed via =npx skills install=
- See [[https://docs.anthropic.com/en/docs/claude-code][claude-code docs]] for documentation
- Skills installed to =~/.claude/skills/=
